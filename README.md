# Tesis doctoral

Este repositorio recoge los scripts desarrollados para la tesis doctoral: "Dinámica de ensamblaje del microbioma rizosférico del tomate".
----------

## Descripción de las carpetas

Todos los scripts están disponibles tanto en formato _.Rmd_ para visualizarlos con R, como en formato _.html_ que pemrite su visualizaicón con un navegador web. 

**Scripts Comunes**
En esta carpeta se encuentran los scripts utilizados en todos los capítulos. 

**Archivos Temporal**
En esta carpeta se encuentran el archivo excell con los metadatos y el script utilizado para el análisis de los datos.

**Archivos Deriva**
